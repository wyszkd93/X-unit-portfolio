■ 메일 백업 검색기 사용법

매달 받는 메일 백업 zip 을 압축 풀지 않고 바로 검색하는 프로그램입니다.
모든 작업은 내 PC 안에서만 이루어지며, 메일 내용이 밖으로 나가지 않습니다.


1. 준비 (처음 한 번)
   - 따로 설치할 것은 없습니다. zip 을 풀기만 하면 됩니다.
     (프로그램 실행에 필요한 Python 이 python 폴더에 들어 있습니다. 이 폴더를 지우지 마세요)
   - 이 폴더는 원하는 곳에 두면 됩니다. (예: D:\메일백업검색기)
   - zip 을 풀기 전에 zip 파일 우클릭 > 속성 > 아래쪽 [차단 해제] 를 체크하면
     실행할 때 "Windows의 PC 보호" 경고가 덜 뜹니다.
     경고가 뜨면 [추가 정보] > [실행] 을 누르세요.

2. 실행
   - [메일검색.bat] 을 더블클릭하면 브라우저에 검색 화면이 열립니다.
   - 처음 실행하면 "메일 백업 폴더 선택" 창이 뜹니다.
     매달 받는 백업 zip 을 모아 두는 폴더를 고르고 [저장하고 시작] 을 누르세요.
     예)  D:\메일백업\
            ├ 202609 메일\받은메일함_1.zip
            └ 202610 메일\보낸메일함.zip
   - 처음 색인은 메일 양에 따라 몇 분 걸립니다. 그동안에도 검색은 됩니다.
   - [바탕화면 바로가기 만들기.bat] 을 한 번 실행하면 바탕화면에 바로가기가 생깁니다.
   - 검은 창(작업표시줄에 최소화됨)을 닫으면 프로그램이 종료됩니다.

2-1. 자동 실행 (선택)
   - [자동 실행 켜기.bat] 을 한 번 실행하면, Windows 에 로그인할 때마다
     검색기가 창 없이 백그라운드로 켜집니다. 새로 넣은 백업 zip 도 그때 자동 반영됩니다.
   - 브라우저에서 http://127.0.0.1:8765 를 열고 Ctrl+D 로 "북마크바" 에 저장해 두면
     북마크 클릭만으로 바로 검색할 수 있습니다.
   - 끄려면 [자동 실행 끄기.bat] 을 실행하세요.

3. 매달 새 백업을 받으면
   - 오른쪽 위 [백업 가져오기] > [파일 고르기] 에서 받은 백업 zip 들을 고르세요. (여러 개 선택 가능)
   - 메일 날짜를 보고 "백업 연월"(예: 202610)을 자동으로 채워 줍니다. 다르면 고치세요.
   - [가져와서 반영] 을 누르면 백업 폴더\202610 메일\ 로 복사하고 바로 반영합니다.
     고른 원본 파일은 지우지 않으며, 이미 들어 있는 같은 파일은 건너뜁니다.
   - 직접 넣어도 됩니다: 백업 폴더에 월 폴더(예: 202611 메일)를 만들고 zip 을 넣은 뒤
     [새 백업 반영] 을 누르세요. (프로그램을 켤 때도 자동 반영됩니다)
   - (선택) 다운로드 폴더에서 자동으로 가져오기 — 기본은 꺼져 있습니다.
     프로그램을 끄고 config.json 을 메모장으로 열어 마지막 줄 } 앞에 아래를 넣은 뒤 다시 켜세요.
       , "auto_import": {"enabled": true, "dir": "C:\\Users\\내계정\\Downloads", "since": "2026-11-01"}
     그러면 5분마다 다운로드 폴더의 받은/보낸/외부메일함*.zip 을 찾아 월 폴더로 복사하고 반영합니다.
     (since 날짜 이후에 받은 파일만, 원본은 그대로 둠)

4. 검색 요령
   - 여러 단어를 띄어 쓰면 모두 포함된 메일만 찾습니다.   예) DB 테이블스페이스
   - 정확한 문구는 따옴표로 묶습니다.                      예) "PM 작업"
   - 빼고 싶은 단어 앞에 - 를 붙입니다.                    예) 배포 -공지
   - 검색창 오른쪽에서 범위(제목/보낸사람/본문/첨부파일명 등)를 고를 수 있습니다.
   - 왼쪽에서 메일함, 연도/월(메일 날짜 기준)로 좁힐 수 있습니다.
   - 키보드: /  검색창   ↑ ↓  메일 이동   Esc  검색어 지우기

5. 메일 보기
   - 첨부파일 카드를 누르면 저장됩니다. (회사 DRM 이 걸린 파일은 원본 그대로 저장됩니다)
   - [EML 저장] 으로 원본 메일을 저장해 더블클릭하면 Outlook 에서 열립니다.

6. 백업 폴더를 바꾸려면
   - 오른쪽 위 톱니바퀴 버튼을 누르세요.

7. 참고
   - 검색 화면 주소: http://127.0.0.1:8765  (이 PC 에서만 열립니다)
   - 실행하면 이 폴더에 mail_index.db (검색용 색인, 메일 본문 포함) 와
     config.json (설정) 이 생깁니다.
     mail_index.db 에는 내 메일 내용이 들어 있으니 다른 사람에게 주지 마세요.
     이 프로그램을 다른 사람에게 줄 때는 처음 받은 zip 파일을 그대로 전달하세요.
   - 색인을 처음부터 다시 만들고 싶으면 프로그램을 끄고 mail_index.db 를 지운 뒤 다시 실행하세요.
